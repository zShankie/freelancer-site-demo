# Freelance Reels Editor — Demo Website

## Description

A simple one‑page website built as a client‑style demo for a freelance Instagram Reels editor.
It highlights services, clarity, and contact information in a clean layout.

## Purpose

This project demonstrates a small, finishable freelance deliverable — the kind of website a creator or editor could use as a personal landing page to attract clients.

## Features

- Hero section with value proposition
- About section for trust
- Services section with three offerings
- Contact call‑to‑action

## Tech Stack

- React (Vite)
- Tailwind CSS

## Run Locally

Clone the project and start the dev server:

```bash
npm install
npm run dev
```

## Deployment

Live site: https://freelancer-site-demo.vercel.app/

## Notes

This is an example of a small freelance web deliverable — focused on clarity rather than features.
